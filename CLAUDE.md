# Browser Vault

macOS приложение, което държи профилите на Brave и Firefox в криптиран контейнер (нативен `hdiutil` APFS AES-256 sparsebundle). Отключване с парола + YubiKey (FIDO2 hmac-secret) или парола + TOTP аутентикатор (Secure Enclave). Пълна спецификация: `docs/SPEC.md`. Тя е източникът на истина; при съмнение питай, не измисляй.

## Структура
- `crates/vault-core` — Rust библиотека: crypto, header, keyslots, hdiutil, процеси, lock тригери
- `crates/bvault-cli` — CLI върху ядрото (за тестове и дебъг)
- `app/src/` — готов frontend (vanilla JS, без build): menu bar, unlock, wizard, settings, i18n `bg` + `en`. Договорът с Rust (команди, събития, прозорци) е в `docs/UI.md`. Не пренаписвай UI-я с framework; свържи го с командите оттам
- `app/src-tauri/` — Tauri 2 shell (създава се в етап M6)
- `docs/` — спецификация и бележки

## Правила за сигурност (задължителни)
- Без собствена криптография. Само одобрените crates от SPEC т. 2. Нов crypto crate само след одобрение.
- Всички ключове и пароли в `Zeroizing<>`. Никога в логове, грешки, panic съобщения, env, аргументи на процеси или temp файлове.
- Паролата към `hdiutil` само през stdin.
- Случайност само от `OsRng`.
- Грешките при отключване са общи („Unlock failed“). Не издаваме кой фактор е сгрешен.
- Записите на header са атомарни (temp → fsync → rename) + `.bak`.
- Съществуващите профили на потребителя са само за четене. Единственото място, където се трият, е `cleanup_original` (SPEC 5.1), и то само след проверка в Rust на `reviewed`, затворен браузър и парола.
- Без мрежови заявки от приложението, освен Tauri updater (M8).

## Работен процес
- Работи по етапите M1→M8 от SPEC т. 9, по един наведнъж. Етапът е готов, когато тестовете от колоната „Приемане“ минават.
- `cargo fmt`, `cargo clippy -- -D warnings`, `cargo test` преди всеки commit.
- Unit тестове за всичко в crypto/header. E2E тестовете, които искат реален Mac, YubiKey или браузър, са маркирани `#[ignore]` с инструкция в коментар как се пускат ръчно.
- Кратки commit съобщения на английски. Код и коментари на английски. UI текстове през i18n.
